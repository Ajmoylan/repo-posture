      GitHub Copilot and developer productivity

      What this project actually implements, kept separate from where Copilot could help next.

      Implemented and verifiable

      • Read-only scanner: 13 controls, pass / fail / unknown, weighted score and coverage
      • CI on Python 3.11–3.13: Ruff, mypy --strict, pytest with a 90% coverage floor
      • CodeQL for Python, JavaScript and the workflows; dependency review on every PR
      • Dependabot, secret scanning with push protection, private vulnerability reporting
      • Ruleset on main: pull request and passing checks required
      • Scheduled posture workflow that publishes its report to the job summary and gates on a minimum score
      • This dashboard, deployed by GitHub Actions to GitHub Pages

      Recommended · not demonstrated here

      • Copilot code completion and Chat: draft a new check and its tests from the existing patterns
      • Copilot Autofix: propose fixes for CodeQL alerts, reviewed in a pull request
      • Copilot code review: a first-pass review on each PR, before the owner's review
      • Copilot coding agent: open draft PRs for small, well-defined issues, held to the same CI and security gates
      • Measuring impact: time from issue to merge, first-run CI pass rate and Copilot usage metrics, before and after adoption

      The project was developed with AI-assisted coding tools; its behaviour is backed by the automated tests and security scans above. No Copilot usage or productivity figures are claimed. Read the Copilot notes ↗
